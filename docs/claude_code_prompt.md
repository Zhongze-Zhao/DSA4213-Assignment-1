## 实验要求（严格对照 PDF）

### Part I：四类语言模型对比（40 分）
在同一训练语料、同一词表上训练并比较：
1. **n-gram 模型**（带平滑或插值，例如 Kneser-Ney 或线性插值，自己实现或用 `nltk`，需说明）；
2. **RNN 语言模型**；
3. **LSTM 语言模型**；
4. **Transformer 语言模型**（因果自注意力 / causal mask）。

要求：
- 三个神经模型都用**随机初始化、可训练**的输入 embedding；每个目标词只能用前面的 token 预测。
- **预测质量**：在同一评估设置下报告 test perplexity / 平均交叉熵，**loss 中排除 padding**。
- **训练与推理成本**：训练时间、参数量、推理时间或吞吐量；写清硬件、训练预算、计时方法，用统一的推理工作负载。
- **学习过程**：画神经模型的 train / validation loss 曲线，讨论收敛与过拟合。
- **生成文本**：用同一组 prompt（3–5 个）、相同的解码设置和生成长度生成续写，比较重复、局部流畅度、一致性。
- 区分「观察到的差异」与「可能的解释」（结构、参数量、上下文长度、训练预算）。
- 架构、超参数、上下文长度、解码设置都要记录在配置文件里。

### Part II：Embedding 消融（30 分）
选 Part I 中一个神经模型（建议 LSTM，请说明理由），比较三种输入 embedding：
1. 随机初始化、与模型一起训练（如果和 Part I 的设置完全一致，可直接复用 Part I 的模型）；
2. 用 **自己在 WikiText-2 训练集上训练的词向量**（如 gensim Word2Vec Skip-gram/CBOW），训练 LM 时**整张 embedding 表固定**；
3. **公开预训练词向量**（如 GloVe 6B），**整张表固定**。

要求：
- 三种设置的 embedding 维度（结合 GloVe 选，例如 100 或 300）、其余结构、数据、训练流程完全相同。
- 报告公开词向量的**词表覆盖率**，以及缺失词如何初始化。
- 比较 test 预测质量、收敛速度、训练稳定性和代表性生成文本。
- **单独报告**训练自有词向量的成本（不算进 LM 训练时间）。
- 解读结果时同时考虑「是否可训练」和「公开词向量用了额外训练数据」这两个因素。

### Part III：下游表示分析（20 分）
- 用 Part I / II 训练好的语言模型做简单监督分类任务，**至少比较两种表示**（例如 LSTM vs Transformer，或两种 embedding 变体，或同一模型的 last hidden state vs 去掉 padding 的 mean pooling）。
- 写清每个输入如何变成定长向量。
- 冻结语言模型，只训练分类器；两种表示用**相同的分类器类型**（如 Logistic Regression）和相同的评估流程。
- 报告 held-out 的 accuracy 和 macro-F1，分析具体错误样例。
- 讨论 LM 的困惑度排名是否与下游分类排名一致。
